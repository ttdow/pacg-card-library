# Pathfinder Adventure Card Game Library

[Open the library](https://ttdow.github.io/pacg-card-library/)

An unofficial, free reference for the original Pathfinder Adventure Card Game.
Browse cards, use interactive character sheets and special-mechanic checklists,
explore the illustrated adventure map, search the interactive rulebook, and
compare dice statistics. Personal selections
are saved in your browser. Feedback is sent privately through Formspree.

This repository contains only the generated static website and its current
public JSON snapshot. The SQLite database, source snapshots, importer,
dependencies, tests, and development files are maintained separately.

Card and mechanic exports exclude flavor text and raw wiki markup. Character
portraits are from Paizo's official Community Use Package. Every card has a
source link; creator acknowledgements and notices are on the
[Credits & licensing page](https://ttdow.github.io/pacg-card-library/credits.html).
The map credits PathfinderWiki Mapping contributors and retains CC BY-NC-SA 4.0
for geographic data; its Paizo illustrations retain their Community Use terms.

Original software uses the [0BSD license](LICENSE.txt). Game text, wiki
contributions, portraits, and other third-party material keep their own terms;
see [code and content terms](LICENSING.txt).

GitHub Pages serves the root of the main branch. No application server or
deployment dependencies are required.
