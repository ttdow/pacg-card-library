# PACG card library

[Open the card browser](https://ttdow.github.io/pacg-card-library/)

A static, read-only reference for the original Pathfinder Adventure Card Game.
Search runs in your browser; individual card details load when selected.

This repository contains only the generated website and the current JSON data
snapshot. The SQLite database, importer, source snapshots, local dependencies,
and development files are maintained separately and are not published here.

Card records include links to their Pathfinder Adventure Card Game Wiki sources,
transcription status, errata, and inventory verification notes. Original artwork,
flavor text, adventure introductions, and character/role biographies are excluded.
Raw wiki markup is not published; search indexes only the retained rules text. This is an unofficial reference collection.

GitHub Pages serves the root of the main branch. No application server or
deployment dependencies are required.
